# Руководство по использованию py2rs

## Установка

1. Убедитесь что установлены:
   - [Rust](https://rustup.rs/)
   - [Node.js](https://nodejs.org/)

2. Запустите `setup.bat`
   - Установит npm зависимости
   - Скачает Rust крейты
   - Соберет проект

## Первый запуск

1. Запустите `start.bat`
2. Появится диалог настройки LLM провайдера
3. Выберите один из вариантов:

### Ollama (рекомендуется для начала)
```
Тип: Локальная / OpenAI-совместимая
URL: http://localhost:11434/v1
Модель: qwen2.5-coder
API ключ: (оставить пустым)
```

Установка Ollama:
```bash
# Windows
winget install Ollama.Ollama

# Запуск модели
ollama pull qwen2.5-coder
ollama serve
```

### llama.cpp
```
Тип: llama.cpp
URL: http://localhost:8080
Модель: имя вашей модели
API ключ: (оставить пустым)
```

### Anthropic Claude
```
Тип: Anthropic API
Модель: claude-sonnet-4-20250514
API ключ: ваш ключ от anthropic.com
```

## Процесс миграции

1. Нажмите "Выбрать папку проекта"
2. Выберите папку с Python кодом
3. Приложение найдет все .py файлы и внешние зависимости
4. Отредактируйте соответствия Python → Rust библиотек если нужно
5. Опишите проект в 2-3 предложениях
6. Нажмите "Начать перенос"

Приложение:
- Построит граф зависимостей между файлами
- Обработает файлы в правильном порядке (от модулей без зависимостей к зависимым)
- Для каждого файла сгенерирует Rust код
- Проверит компиляцию через `cargo check`
- При ошибках попытается исправить (до 4 попыток)
- Создаст отчет в `<проект>_rs/REPORT.md`

## Результат

Создается папка `<ваш_проект>_rs/` с:
- `Cargo.toml` - манифест проекта
- `src/lib.rs` - главный файл библиотеки
- `src/*.rs` - мигрированные модули
- `REPORT.md` - отчет о миграции

Файлы помечаются:
- ✓ Компилируется - файл успешно собирается
- ⚠ Есть ошибки - требуется ручная правка

## Кэширование

Успешные переводы кэшируются в:
```
C:\Users\<user>\AppData\Local\py2rs\cache\
```

При повторной миграции того же файла будет использован кэш.

## Советы

1. **Начните с малого** - сначала мигрируйте небольшой модуль
2. **Проверьте зависимости** - убедитесь что Rust-аналоги корректны
3. **Добавьте документацию** - кликните 📝 у библиотеки и опишите как её использовать
4. **Описывайте проект** - это помогает LLM понять контекст и делать лучший перевод
5. **Используйте мощные модели** - qwen2.5-coder:32b лучше чем :7b

## Расширение библиотек

Отредактируйте `src-tauri/src/crate_map.rs`:

```rust
("requests", Info {
    crate_hint: "reqwest",
    doc: "HTTP client: reqwest::Client::new().get(url).send().await"
}),
```

После изменений пересоберите: `cargo build --release`

## Устранение проблем

### "Workspace still starting"
Подождите 5-10 секунд, Linux окружение инициализируется

### Ошибки компиляции не исправляются
- Проверьте что все крейты корректны
- Добавьте документацию к библиотеке (📝)
- Используйте более мощную модель
- Исправьте вручную глядя на REPORT.md

### Медленная работа
- Используйте GPU ускорение для локальных моделей
- Попробуйте API провайдера вместо локальной модели
- Уменьшите размер проекта (мигрируйте по частям)
